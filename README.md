# BIRL website

Upload index.html, style.css and script.js to the root of iida238jp/birlab-website, replacing the existing HTML and CSS. GitHub Pages should use main / (root).

The site contains Research, People, Publications, Community and Join sections. Research details expand in place. The member directory and research photos come from birlab.org; external photographs remain hosted there. Videos open on YouTube. Publication images illustrate themes, not necessarily the linked paper.

No build or installation is needed. Open index.html in a browser to preview.

Validation: internal anchors, unique IDs, image alt text and local file references passed. Browser rendering and JavaScript execution could not be verified in this environment.
